# TecFest2k24 Website

Website for TecFest2k24, the CSE department symposium at Tagore Engineering College (March 26, 2024).
Static HTML/CSS/JS, hosted on GitHub Pages.

## Structure

- `index.html` – home page (about, events, location, contact)
- `<event-name>.html` – one page per event
- `crichase-carnival.html`, `quizzy-quirks.html` – redirects kept so old shared links still work
- `styles.css` – site-wide styles, `style.css` – event page styles
- `app.js` – mobile menu and countdown (event date is the `EVENT_DATE` constant)
- `images/`, `videos/` – assets (lowercase, hyphen-separated names)
